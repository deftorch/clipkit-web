# ClipKit Validation Rules & Thresholds Reference

> Auto-generated by `npm run build:skill`. Do not edit manually.

This reference documents the diagnostic rule codes, severity levels, and mathematical thresholds enforced by ClipKit's validation engine.

## Diagnostic Severity Levels

- `FAIL`: Unacceptable violation of anatomical constraints, physics boundaries, or schema integrity. Disallows publication.
- `WARN`: Biological implausibility, potential foot sliding, or high acceleration that may degrade animation quality.
- `INFO`: Structural notifications, layer duration adjustments, or performance tips.

## Biological & Floor Constraints

- **Knee Flexion**: `-5°` to `160°` (knees only bend backwards).
- **Elbow Flexion**: Max `150°` (elbows only bend inward).
- **Neck Bending**: Max `70°` total inclination.
- **Floor Penetration**: Max `0.04m` below ground baseline ($Y < 0$).
- **Foot Slide Threshold**: Ground movement exceeding `0.25 m/s` during active planted windows emits `FOOT_SLIDE`.
